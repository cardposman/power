# 역별 페이지 200개 로컬 확장

작업일: 2026-10-20

## 범위

사용자가 기존 200곳을 출발점으로 규모를 유지하기로 한 후, 해당 후보 전체를 로컬 검토 페이지로 생성했다. 선행 조사의 유지 14·조건부 12·통합검토 5·보류 19·추가 심층 미검토 150이라는 상태는 데이터에 그대로 남겼다. 페이지 생성은 시장성 검증 결과를 바꾸지 않는다.

- 기존 287페이지: 메인 1, 시·군·구 269, 광역별 목록 16, 전국 지역 목록 1.
- 추가 213페이지: 역별 200, 권역별 역 목록 12, 전국 역 목록 1.
- 합계 500페이지. 기존 지역 페이지의 학교명 상담 내용은 그대로 유지했다.
- 이번에는 명단 교체·역 병합을 하지 않았다. 인접 후보는 서로 다른 역이며, 통합검토 판단을 별도 데이터로 보존했다. 가까운 역의 검색 의도가 서로 다르다고 검증했다는 뜻은 아니다.

## 경로와 탐색

- 전국 역별 목록: `station/index.html`.
- 권역별 목록: `station/{regionSlug}/index.html`.
- 개별 역: `station/{regionSlug}/{candidateId}/index.html`. 번호는 3자리이며 최초 명단의 고정 식별자다. 철도 운영기관의 역 번호가 아니다.
- 예: 강남 `station/seoul/001/index.html`, 대구 중앙로 `station/daegu/168/index.html`, 대전 중앙로 `station/daejeon/183/index.html`.
- 죽전·중앙로 같은 동명역은 권역과 경로로 구분한다. `동대구역`처럼 원래 이름에 ‘역’이 있는 항목에 접미사를 중복 추가하지 않는다.
- 경남 양산·수로왕릉과 경북 영남대·정평은 노선 운영 권역과 행정 권역을 혼동하지 않도록 각각 경남·경북 목록에 넣었다.
- 역 목록은 권역별로 펼쳐서 볼 수 있다. 사용자 요청에 따라 지역·역 목록의 검색창과 검색 동작을 제거했다. 대표 노선 표시는 역 식별용이며 전체 환승 노선이나 현재 운행 상태의 보증이 아니다.
- 메인과 기존 지역 페이지의 하단에서 역별 목록으로 이동할 수 있고, 두 종류의 목록 사이를 전환할 수 있다. 상단 카테고리 메뉴의 ‘역별 상담’은 사용자 요청에 따라 제거했다.

## 화면과 내용

- 기존 주황색 스타일과 PC·모바일 공통 최대480px 단일 열을 유지했다.
- 첫 화면 순서는 기존 요청대로 썸네일, 상품 소개, 본문 이미지다.
- 썸네일은 기존 4종 중 경로 해시로 고정 배정한다. 매번 열 때 달라지는 방식이 아니어서 JavaScript 없이도 같은 이미지가 나온다.
- 제목 형식: `{권역} {역명} 맨투맨 일본어회화 일대일 과외수업 | TS재팬`.
- 메타설명은 역의 정체성과 학습 목적별 상담 내용을 담고, 화상수업임을 설명한다.
- 상품 소개에서 ‘해당 역 주변의 오프라인 교실 안내가 아님’을 명시한다. 출구별 교실·현지 지점·방문수업·운영 실적을 만들지 않았다.
- 역별 상담 영역에는 학교명을 자동 삽입하지 않는다. 목표별 설명, 과정 비교 기준, 상담 준비 항목 3개, 관련 질문과 답변을 제공한다.
- 공유하는 안내 주제는 업무, 학업/시험과 회화, 생활 일정, 생활회화, 기초 학습의 5종이다. 처음 배정은 초기 후보의 선정 가설을 따랐다. **그 역의 실제 수강생 구성이나 주된 수요를 조사해 확정한 것이 아니다.**
- 전체 상품·교재 정보는 제공된 자료와 기존 페이지를 공유한다. 타 학원의 문구·시간표·후기를 우리 서비스 정보로 사용하지 않았다.

## 중요한 한계

200곳 모두의 독자적인 지역 교육 정보를 확보한 것은 아니다. 5종의 목적별 안내와 공통 상품 정보를 공유하므로 **200개의 완전히 독립적인 원고나 유사문서 문제 해결을 보장하지 않는다.** 이름·썸네일·동의어 변경 자체를 검색 품질의 근거로 삼지 않는다.

같은 생활권에 유용한 차이가 부족한 경우 통합할 필요가 있다는 선행 의견은 유효하다. 실제 운영자가 확인한 수업 예시·구체적인 과정·상담 질문·지역별로 제공 가능한 차이가 있으면 데이터를 보완하고, 차이가 없으면 독립 페이지 발행 필요성을 다시 판단한다. 이 단계의 200개는 사용자가 선택한 규모의 로컬 검토 대상이다.

월간검색수·문의수·전환율·자연검색 경쟁도는 미확인이다. 검색 순위나 수요 상위 200곳이라는 표현을 사용하지 않는다. 정책 근거와 조사 출처는 [초기 목록](station-shortlist-20261020.md)과 [A군 조사](station-validation-20261020.md)에 있다.

## 재생성과 검증

```powershell
node scripts/generate-regions.cjs
node --test scripts/test-stations.cjs
python scripts/check-generated.py
```

`data/stations.json`이 생성용 원본이며, `guide`를 역별로 수정할 수 있다. 초기 조사 문서에서 전체 데이터를 다시 가져올 때만 `node scripts/import-stations.cjs`를 실행한다. 재가져오기는 수동 수정한 주제 배정을 덮어쓴다. 조사 문서의 번호나 표 구조를 임의로 바꾸면 가져오기 검증이 실패한다.

브라우저 검증은 `scripts/check-stations.cjs`를 사용한다. 200개 역의 375px 표시, 목적별·긴 이름·동명역 대표 사례의 320/1440px 표시, 이미지, 과정 탭, 추가 질문, 권역 펼치기, 목록 이동을 검사한다. 검색창과 상단 역별 메뉴가 없는지도 검사한다. 기존 메인·지역용 검증 스크립트도 유지했다.

이번 검증 결과:

- 후보 가져오기·동명역·권역·오류 입력 단위 테스트 4개 통과.
- 500페이지의 링크·이미지·앵커 검사, 끊어진 링크 0건.
- 역별 200페이지의 375px 검사와 대표 13페이지의 320/1440px 검사 통과.
- 동명역 구분·과정 탭·추가 질문·목록 간 이동 통과, JavaScript 오류 0건. 이후 검색 기능·상단 역별 메뉴 제거에 맞춰 검증도 변경했다.
- 기존 메인 320~1440px의 7개 화면 폭 검사, 기존 시·군·구 269페이지 및 대표 8사례의 좁은 모바일/PC 검사 통과.
- 생성된 화면 스크린샷을 확인했다. 검증 결과와 스크린샷은 Git에서 제외된 `verification/`에 저장한다.

## 배포 상태

이번 작업은 로컬 생성과 검증만 수행한다. 기존 `origin` 설정과 색인 차단 상태를 유지하며, 배포 ZIP·커밋·푸시·서버 배포는 하지 않는다. 기존 `dist-netlify`와 ZIP은 이번 역별 페이지를 포함하지 않을 수 있으므로 최신 결과로 오해하지 않는다.
