# 역별 일본어 수업 페이지 후보 50곳 보완 검토

조사일: 2026-10-20

후속 작업: 사용자가 200곳 유지로 진행하기로 결정한 뒤 [로컬 페이지 확장](station-expansion.md)을 별도로 수행했다. 아래 조사 판단과 당시 작업 범위는 그대로 보존한다.

## 1. 결론

기존 200곳 중 **A 검토군 50곳**을 공개자료로 추가 검토했다. 이 단계에서는 200곳을 그대로 제작하기보다, **유지 14곳을 먼저 콘텐츠 기획 대상으로 남기는 것**을 권한다. 14곳도 수요·검색량이 입증되거나 독립 페이지 제작이 확정된 곳은 아니다.

| 판단 | 수량 | 의미 |
| --- | ---: | --- |
| 유지 | 14 | 운영기관 자료에서 일본어 과정과 관련 권역을 비교적 구체적으로 확인. 다음 기획 대상으로 유지 |
| 조건부 | 12 | 권역 안내, 지점 목록, 사업자 직접 작성 소개 등은 있으나 현재 과정·정확한 위치·독립 콘텐츠 중 추가 확인 필요 |
| 통합검토 | 5 | 인접 후보와 별도 페이지를 만들 이유가 아직 부족. 생활권 단위 기획을 먼저 검토 |
| 보류 | 19 | 이번 조사로 해당 역의 현재 일본어회화 공급 또는 상품 적합성을 충분히 확인하지 못함 |
| **합계** | **50** | **검색 수요 순위가 아닌 조사 후 편집 판단** |

**권고:** 우선 14곳 중 서로 다른 학습 목적을 설명할 수 있는 소수 사례를 기획하고, 실제 제공 가능한 정보가 없는 역은 독립 페이지를 만들지 않는다. 조건부 12곳까지 포함해도 후보는 26곳이지, 곧바로 발행할 26페이지라는 뜻은 아니다. 나머지 B군 150곳은 이번 심층 검토 대상이 아니다.

## 2. 무엇을 확인했고, 무엇을 확인하지 못했는가

### 확인한 범위

- 운영기관의 일본어 강좌·캠퍼스·위치 안내, 일부 최근 모집 공지, 사업자가 직접 작성한 채용·업체 소개를 확인했다.
- 과정이 회화·기초인지, JLPT·EJU·취업연수 중심인지 구분했다. 일본어라는 공통점만으로 모두 회화 수요로 묶지 않았다.
- 상권 명칭과 실제 역을 구분했다. 같은 학원의 캠퍼스를 인접한 여러 역의 독립 근거로 중복 계산하지 않았다.
- 현재 상품은 **1:1 화상수업**이다. 근처 학원이 있다는 사실이 우리 상품의 오프라인 지점이나 방문수업을 뜻하지 않는다.

### 확인하지 못한 범위

- **50곳 모두 월간검색수, 상담수, 전환율, 자연검색 경쟁도는 미확인**이다. 학원 존재는 교육 공급의 신호일 뿐 실제 수요량은 아니다.
- 사용 가능한 웹 검색 도구의 결과와 공개 원문을 조사했다. 네이버 실시간 검색 결과 상위 N개를 동일 조건으로 전수 수집·분류한 조사가 아니다. 오프라인 검색 의도의 비율이나 경쟁 강도를 숫자로 제시하지 않는다.
- 역별 모든 조합을 동일 횟수로 검색한 실험이 아니다. 일본어학원·회화·과외·운영기관·지점 이름을 조합해 후보별 근거를 탐색했다.
- 검색 스니펫과 열람 가능한 본문이 다를 때는 본문을 우선했다. 열람 차단, 과거 공지, 업체 소개만 확인된 경우 아래에 따로 표시했다.
- 찾아내지 못했다고 해서 해당 역에 학원이 없거나 수요가 적다고 결론 내리지 않았다. 통합검토 역시 물리적으로 같은 상권이라는 확정이 아니다.
- 다른 업체의 자료는 시장 검토용이다. 우리 업체의 수업 실적·지점·가격·시간표·수강 후기처럼 홈페이지에 옮겨 쓰면 안 된다.

## 5. 기존 방식에서 고쳐야 할 점

### 학교명 문단을 역별 페이지에 그대로 쓰지 않기

현재 `scripts/site-data.cjs`의 `localParagraph()`는 학교명 4~5개, 학년, 학교 일정을 중심으로 한 6개 문단을 선택한다. `scripts/generate-regions.cjs`의 지역 상담 제목도 학생 중심이다. 학교 수요를 겨냥한 기존 지역 페이지와 달리 이번 후보에는 성인 수업 상권이 포함되므로 **같은 문단을 가져오면 검색 의도와 내용이 어긋날 수 있다.**

이것은 기존 페이지를 이번에 일괄 수정했다는 뜻이 아니다. 역별 기획에는 학교명 자동 삽입을 기본값으로 쓰지 않는 것이 좋다는 제안이다.

### 유사문서 문제는 단어 교체만으로 해결되지 않음

현재 방식의 문단 변형·학교명 교체·썸네일 변경은 중복 문제를 해결했다는 증거가 아니다. 네이버는 의미 없는 유사 템플릿 대량 발행과 부자연스러운 키워드 반복을 문제 사례로 안내한다. [공식 스팸사례](https://searchadvisor.naver.com/guide/content-abusing), [콘텐츠 권장 사항](https://searchadvisor.naver.com/guide/content-basic).

따라서 ‘유사도 회피’ 자체보다 방문자가 얻는 **실제 다른 정보**를 기준으로 페이지를 나눈다. 비교 기준, 제공 가능한 과정, 학습 목적별 수업 예시 등은 우리 운영자가 확인한 사실로 작성하고, 그 차이가 없는 인접 역은 합치거나 독립 발행을 보류한다. 콘텐츠에 없는 학원·방문수업을 제목에 넣어 유입시키지 않는다.

### 화상수업임을 숨기지 않기

공개자료에서 확인한 다수 기관은 현장 수업이나 현장/온라인 선택을 제공한다. 이것만으로 검색 사용자의 오프라인 선호 비율을 산출할 수는 없지만, **역명 검색에 오프라인 기대가 섞일 가능성**은 고려해야 한다. 우리 페이지 첫 화면과 상담 동선에서는 1:1 화상수업을 명확하게 알리고, 해당 역 주변 교실이 있는 것처럼 주소·출구 안내를 만들지 않는다.

## 6. 추가 데이터가 있으면 달라지는 부분

1. 네이버 검색광고 키워드도구의 역별 관련어 월간검색수 내보내기가 있으면, 공급 신호 위주의 현재 후보를 검색 수요 기준으로 다시 비교할 수 있다. 도구 접근/내보내기 자료는 이번에 확보하지 못했다. [공식 도움말](https://ads.naver.com/help/faq/1406).
2. `역명+일본어`, `역명+일본어회화`, `역명+일본어과외`, `역명+일본어학원`, `역명+화상일본어`를 같은 조건으로 비교한다. ‘일본어’ 조회수가 있다고 전부 1:1 화상수업 수요로 합산하지 않는다. 낮은 검색량 범위 표시는 정확한 숫자로 바꾸지 않는다.
3. 실제 상담에서 지역/역·학습 목적·원하는 수업 방식·유입 페이지를 확인할 수 있으면, 후보 유지 여부를 다시 판단한다. 개인정보는 필요한 범위만 수집한다.
4. 페이지 발행 이후 성과를 평가하려면 배포 주소와 색인 가능 상태부터 확인해야 한다. 현재 **로컬** `data/site.json`의 `origin`은 비어 있고 `index.html`은 `noindex,nofollow`다. 서버의 현재 응답을 검사한 결과는 아니며, 이번 조사에서 이 설정을 변경하지 않았다.
