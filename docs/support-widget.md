# 통합 상담 위젯 연결

- 운영 주소: https://tstudymate.com
- 사이트 ID: `tstudymate` — 일본어·영어 공통
- 관리자 표시 이름: TS맨투맨회화
- 공통 위젯: https://lxrjy-92bbd.web.app/widget.js
- 공개 설정: https://lxrjy-92bbd.web.app/config.json

2026-11-17에 chat 프로젝트의 `docs/integrations/tstudymate.md`, 공통 README와 `snippets/tstudymate.js`를 기준으로 연결했다. Firebase·인증·공통 위젯 소스는 이 저장소에서 관리하지 않는다.

## 설치와 생성

`assets/js/site.js` 끝의 독립 IIFE 한 개가 정확한 운영 Origin에서만 공통 위젯을 불러온다. 로컬·file 미리보기는 제외하며 운영 인증 정책을 완화하지 않는다. 기존 loader ID 또는 위젯이 있으면 추가하지 않는다. 별도 외부 script 태그는 템플릿에 넣지 않는다.

일본어 504개와 영어 500개, 총 1,004개의 콘텐츠·목록 페이지가 공통 JS를 한 번씩 사용한다. 이전 경로 호환용 리다이렉트는 안내 페이지로 이동한 뒤 적용된다. 네이버 일본어·영어 상담 링크, 메뉴와 학습 과정 탭은 유지한다.

`templates/lesson.html`, `english-lesson.html`, `category.html` 및 두 언어 목록 생성기는 공통 JS/CSS의 내용 해시를 URL에 넣는다. `scripts/shared-assets.cjs`가 버전을 계산하므로 JS/CSS 변경 후 전체 페이지 재생성 시 새 버전을 읽는다. 소스는 기존 지역별 폴더에 보관하고 짧은 공개 경로는 `_site/` 빌드에만 생성한다.

## 배치

제공된 삽입 코드가 `.fixed-contact`의 보이는 높이를 읽어 `--support-bottom`을 높이 + 16px로 설정한다. 고정바의 크기 변경, 스크롤, 창 크기 변경에도 다시 계산한다. `site.css`의 `--support-right`는 중앙 480px 페이지의 오른쪽에 맞추고 좁은 화면에서는 12px를 남긴다. 위젯 내부 Shadow DOM과 공통 CSS는 수정하지 않는다.

공통 패널의 높이 제한과 내부 스크롤은 공통 위젯에서 제공한다. 검사에는 패널뿐 아니라 입력창·전송·닫기 버튼의 화면 내 위치와 클릭 가능 여부도 포함한다. 브라우저 화면 크기 검사는 실제 휴대폰 소프트웨어 키보드·물리적 알림 검증을 대신하지 않는다.

## 검증과 실제 상담

`node --test scripts/test-support-widget.cjs`는 외부 통신 없이 Origin 제한, 중복 방지, DOM 준비, 하단 여백, 기존 메뉴, 전체 페이지의 단일 공통 JS를 확인한다. 기존 workflow의 검증 목록에도 포함한다. 기존 페이지·영어 원고·경로 검사도 유지한다.

실제 운영 검증 결과와 적용 commit은 작업 완료 보고에 기록한다. 운영 주소에서 사이트명·연결·입력 활성화를 확인한 뒤 사용자가 관리자 휴대폰을 준비했다고 알려주면 사이트명이 포함된 테스트 메시지 **한 번**만 보낸다. 테스트 전에 메시지나 알림을 발생시키는 자동 반복 검사를 하지 않는다.

실제 상담 확인 항목:

- TS맨투맨회화로 분류: 사용자 확인 전 미검증
- 휴대폰 알림 도착 및 해당 상담방 이동: 사용자 확인 전 미검증
- 관리자 앱 답장의 고객 웹 실시간 수신: 실제 답장 후 확인
- 새로고침 후 동일 브라우저 상담 내역 복원: 테스트 메시지 후 확인
- vending 상담과의 분리: 실제 관리자 화면에서 사용자 확인 필요

인증이나 서버 문제를 발견하면 원인과 필요한 변경을 chat 프로젝트에 전달하며, 관리자 비밀번호·개인 토큰·서비스 계정은 이 저장소에 저장하지 않는다.

## 되돌리기

공통 JS 끝의 위젯 IIFE를 제거하고 페이지를 재생성·배포한다. 필요하면 위젯 정렬용 CSS도 제거한다. 접수된 상담이나 Firebase 데이터는 삭제하지 않는다.
